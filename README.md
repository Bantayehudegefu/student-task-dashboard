# Student Task Dashboard

## Project Objective

Complete a frontend task management application using HTML, CSS, JavaScript, Git, GitHub, teamwork workflow, and responsive design principles.

The goal of this project is to practice frontend development skills and Git collaboration techniques, including branch management and merge conflict resolution.

---

## Features Implemented

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Display total number of tasks
* Display completed tasks count
* Display remaining tasks count
* Responsive user interface
* Dynamic task updates using JavaScript

---

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## How to Run the Project

1. Clone the repository:

```bash
git clone repository-link
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use VS Code Live Server for the best experience.

## Git Workflow

1. Create a new feature branch:

```bash
git checkout -b feature-yourname
```

2. Make changes and commit regularly:

```bash
git add .
git commit -m "Describe your changes"
```

3. Pull the latest changes:

```bash
git pull
```

4. Resolve any merge conflicts if they occur.

5. Push your branch:

```bash
git push origin feature-yourname
```

6. Create a Pull Request on GitHub.
